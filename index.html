Manual de Supervivencia CSS

La guía definitiva para entender la sintaxis y no perderse en los puntos.

1. La Regla de Oro (Sintaxis)

CSS es un lenguaje de diseño, no de programación lógica. Es una lista de órdenes visuales.

Contenedor { 
    Propiedad: Valor; 
}
  • Propiedad: ¿Qué quieres cambiar? (ej. Color, Tamaño).
  • Valor: ¿Cómo lo quieres? (ej. Rojo, 20px).
  • ¡OJO! Siempre termina con punto y coma (;).

2. El Misterio del Punto (.)

¿Por qué algunos nombres llevan punto y otros no? Todo depende de a quién llamas.

body
Sin punto = Etiqueta HTML

Afecta a TODOS los elementos de ese tipo (todas las <p>, todos los <h1>).

.caja
Con punto = Clase (Class)

Es un nombre inventado por ti. Afecta solo a quien tenga class="caja".

3. Ejemplo Real: Etiqueta vs Clase

👉 Etiqueta (Si quieres afectar a todos)

/* Sin punto */
button {
   background: gray;
}

Esto pintará GRIS a todos los botones de la web.

👉 Clase (Si quieres ser específico)

/* Con punto */
.boton-magico {
   background: purple;
}

Esto pintará VIOLETA solo al que tenga class="boton-magico".

Pseudo-clases: Estados y Lógica

Analogía: El "Estado de Ánimo"

Las pseudo-clases definen CÓMO está el elemento en un momento específico.
No es solo "un botón", es "un botón cuando le pasan el mouse por encima" (:hover) o "un botón desactivado" (:disabled).

¡Interactúa conmigo!

1. Interacción (El Mouse y Teclado)

  • :hover → Cuando el mouse está encima.
  • :active → Mientras mantienes el clic presionado.
  • :focus → Cuando el elemento está seleccionado (cursor dentro).
  • :visited → Enlaces que ya visitaste (historial).
.btn:hover { background: gold; }
.input:focus { border: 2px solid blue; }
1. :first-child
2. :nth-child(2)
3. :nth-child(3)
4. :last-child

2. La Familia (Estructura)

Para seleccionar elementos según su posición, sin inventar clases nuevas.

  • :first-child → El primer hijo.
  • :last-child → El último hijo.
  • :nth-child(2) → El segundo hijo (o par/impar con 'even'/'odd').
  • :not(.rojo) → Todos MENOS los que tengan clase "rojo".

3. Formularios y Estados

  • :checked → Checkboxes o radios marcados.
  • :disabled / :enabled → Campos bloqueados o activos.
  • :valid / :invalid → Si el dato (ej. email) es correcto.
  • :empty → Elementos que no tienen nada dentro.

El Concepto de Interpolación

Analogía: El GPS

Imagina que pones una ruta en Google Maps. Tú solo dices "Estoy aquí" (Punto A) y "Quiero ir allá" (Punto B). El GPS calcula automáticamente toda la ruta intermedia.
¡Eso es interpolar! El navegador calcula los pasos intermedios por ti.

A (0px)
B (300px)

👆 Pasa el mouse sobre la caja para ver el viaje

Del Punto A al B

Nosotros definimos el inicio y el final. CSS se encarga de dibujar los 60 cuadros por segundo para que se vea fluido.

CSS 
.caja {
    /* PUNTO A: Inicio */
    transform: translateX(0px);
    
    /* Decimos al GPS: "Calcula el viaje en 1 segundo" */
    transition: transform 1s; 
}

.caja:hover {
    /* PUNTO B: Destino */
    transform: translateX(300px);
}
02

CSS Transitions

Analogía: La Puerta Automática

Una puerta automática no se mueve sola porque sí. Necesita que alguien se acerque (un estímulo) para abrirse.
Las transiciones son iguales: necesitan una interacción (como poner el mouse encima) para activarse.

Transformación Múltiple

Cambio de color, forma (radio de borde) y tamaño al mismo tiempo.

.boton {
  background: blue;
  border-radius: 5px;
  /* Prepara el motor de animación */
  transition: all 0.5s; 
}

/* Cuando el usuario interactúa (:hover) */
.boton:hover {
  background: red;      /* Cambio 1 */
  border-radius: 50px;  /* Cambio 2 */
  transform: scale(1.1);/* Cambio 3 */
}
Carta

Efecto 3D (Giro)

Usamos rotateY para girar la tarjeta como una moneda.

.carta {
  transition: transform 0.6s;
}

.carta:hover {
  /* Girar 180 grados en el eje Y */
  transform: rotateY(180deg);
}

Curvas de Velocidad (Timing)

Analogía: Tipos de Corredores

Imagina una carrera de 100 metros:
1. Linear: Un robot que corre siempre a la misma velocidad exacta.
2. Ease-out: Un corredor cansado, empieza rápido pero llega frenando.
3. Bezier: Un corredor loco que se pasa de la meta y luego retrocede.

linear El Robot (Constante)
ease-out Frenado Natural
cubic-bezier Efecto Rebote

04

Keyframe Animations

Analogía: El Guion de Teatro

A diferencia de la puerta automática (transición), una obra de teatro sigue un guion paso a paso, ocurra lo que ocurra.
Los Keyframes son ese guion: "En el minuto 1 haces esto, en el minuto 2 haces aquello". No necesita interacción, ¡actúa solo!

🎓 Master Class: Creando una Animación desde Cero

Para animar con Keyframes necesitamos dos pasos obligatorios: Crear y Llamar.

PASO 1: EL GUION

Definir los @keyframes

Le ponemos nombre a la animación y definimos qué pasa en cada momento.

/* Creamos la animación "rebotar" */
@keyframes rebotar {
  0% { 
    transform: translateY(0); 
    background: blue;
  }
  50% { 
    transform: translateY(-50px);
    background: red;
  }
  100% { 
    transform: translateY(0);
    background: blue;
  }
}
PASO 2: EL ACTOR

Asignar la propiedad 'animation'

Elegimos qué elemento HTML va a interpretar ese guion.

.pelota {
  width: 50px;
  height: 50px;
  border-radius: 50%;
  
  /* Llamamos al guion por su nombre */
  /* nombre | duración | repetición */
  animation: rebotar 2s infinite;
}

Resultado: La clase .pelota ejecuta los @keyframes rebotar.

Loader Infinito

El código define el guion (`@keyframes`) y luego se lo asignamos al actor (`animation`).

/* 1. Escribimos el Guion */
@keyframes girar {
  0%   { transform: rotate(0deg); }   /* Inicio */
  100% { transform: rotate(360deg); } /* Final */
}

/* 2. Asignamos el papel al actor */
.anillo {
  /* Nombre | Duración | Estilo | Repetición */
  animation: girar 2s linear infinite;
}

Nivel 3: Cubic-Bezier Morph

Un loader con personalidad. Combina 3 propiedades a la vez y usa una curva de velocidad personalizada.

CSS - Curva Personalizada 
.loader {
  /* Gira, escala y cambia forma */
  /* La curva "resorte" */
  animation-timing-function: 
    cubic-bezier(0.68, -0.55, 0.27, 1.55);
}
Reto de Comprensión:

¿Notas cómo el cuadrado "toma impulso" hacia atrás antes de girar? Eso lo hacen los valores negativos en el cubic-bezier.
